# Game-Theoretic Cybersecurity Analytics
Interactive Streamlit project for strategic analysis of cyber attack and defense.

Features: editable utility matrix, equilibrium mixed strategies, payoff heatmap, six scenario comparison, strategy entropy, sensitivity analysis and CSV exports.

## Run locally
```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
streamlit run app.py
```
All utility scores are hypothetical, not measured security outcomes. No attacks are executed.
